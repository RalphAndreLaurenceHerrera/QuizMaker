GitHub Pages Deployment

This application runs 100% client-side with zero external build tools required. Commit these files directly to the root of your GitHub repository and enable GitHub Pages under Settings > Pages.

CSV Format Specification

The CSV file must match this standard format:

type,question,options,correct,box,explanation
single,"Capital of France?","Paris|Lyon|Marseille","Paris",1,"Paris is the capital and largest city."
multiple,"Select prime numbers:","2|3|4|9","2|3",1,"2 and 3 have only two positive factors."

Adaptive Leitner Weight Formula

  • Box 1: Weight multiplier 4.0 (Maximum priority review)
  • Box 2: Weight multiplier 2.0 (Intermediate review)
  • Box 3+: Weight multiplier 1.0 (Proficient cards)
  • Correct Answer: Promotes item +1 box (up to Box 5).
  • Incorrect Answer: Immediately resets item to Box 1.
